# Planificador-de-rutas-sostenibles--Guadalajara-
Aplicación Java que permite planificar viajes sostenibles en Guadalajara comparando caminata, bicicleta, patín eléctrico, autobús, metro y taxi. Calcula tiempo, costo y emisiones de CO₂, y recomienda la opción más equilibrada, ecológica y rápida. Utiliza arquitectura MVC y está preparada para futuras mejoras y expansión.
